# Project lessons

- 2026-11-10 (claude-opus-5-5) Keep chase5ws README plain: no emoji headings, badge walls, skill-icon strips, view counters or decorative SVG banners — the owner reads them as AI-made.
- 2026-11-10 (claude-opus-5-5) ChaseOS site: keep it simple, one desktop icon = one thing (no folders with lists inside, no widgets/quick settings/snap/settings app, no lock screen); dark daedalOS-like look with animated Vanta waves; project icons are each project's own image (os/icons/), drawn tiles only when a project has none; desktop starts with no window open. Never use the Windows logo or other Microsoft marks.
- 2026-11-10 (claude-opus-5-5) When changing anything in os/, bump the ?v= value on the os/ links in index.html, or browsers keep a cached old file next to the new page and the desktop breaks.
- 2026-11-10 (claude-opus-5-5) README images come from the Metrics workflow: if you rename or add a metrics card, the image stays broken until the workflow runs. The workflow now runs on push when README.md or metrics.yml change.
- 2026-11-10 (claude-opus-5-5) Taskbar stays minimal: start button on the left, time on the right, nothing else.
